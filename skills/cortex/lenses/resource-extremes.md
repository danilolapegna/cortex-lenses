# Resource Extremes

Use extreme resource conditions to expose the real bottleneck.

## Steps

1. Freeze the outcome that must still be achieved.
2. Imagine almost no time, people, funding or infrastructure; find the indispensable function.
3. Imagine the blocking resource is abundant and find the next bottleneck.
4. Translate a useful principle from each extreme back to current means.

## Use it when

The design appears inseparable from a resource limit.

## Leave it out when

The extreme requires weakening the objective to produce any idea.
