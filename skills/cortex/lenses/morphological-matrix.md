# Morphological Matrix

Build alternatives by recombining the meaningful dimensions of a solution.

## Steps

1. Choose three to five independent design dimensions.
2. List genuinely different values for each and mark known incompatibilities.
3. Combine one value per dimension, including unfamiliar combinations.
4. Explain how each candidate would achieve the whole outcome.
5. Preserve different mechanisms rather than padding the set with cosmetic variants.

## Use it when

The design space contains several choices that can vary independently.

## Leave it out when

The dimensions are aliases for the same decision.
