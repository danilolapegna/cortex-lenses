# Reframe the Question

Turn a blocking question into an answerable decision question.

## Steps

1. Quote the question and identify its hidden premise.
2. Name the decision or concern it is trying to resolve.
3. Write a question that addresses that concern without importing the premise.
4. Answer it and explicitly account for the original concern.

## Use it when

A loaded question prevents a useful discussion.

## Leave it out when

A direct factual question already deserves a direct answer.
