# The Core Verb

Strip the problem to a transferable function before searching other domains.

## Steps

1. Express the need as a verb acting on an object.
2. Find distant fields that perform that function by different mechanisms.
3. Map a mechanism back to the actual resources and constraints.
4. Name the preserved relationship, the breaking point and a small transfer test.

## Use it when

The domain vocabulary hides a familiar function.

## Leave it out when

The shared verb does not preserve the causal structure.
