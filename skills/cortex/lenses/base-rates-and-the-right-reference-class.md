# Base Rates and the Right Reference Class

Anchor a forecast in a defensible comparison group.

## Steps

1. Define the event, horizon and selection process.
2. Compare reference classes by mechanism, maturity and sampling.
3. Use a class with adequate observations and state its biases.
4. Update with case evidence; show whether another reasonable class reverses the decision.

## Use it when

An exceptional story is driving a material forecast.

## Leave it out when

No defensible observations exist; keep the estimate unknown instead.
