# The Ordinary Fix

Look beside an elaborate intervention for a sufficient everyday repair.

## Steps

1. State what the elaborate solution must accomplish.
2. Try a small parameter change, reuse or removal.
3. Explain how the ordinary fix would cover the complete need.
4. Expose hidden maintenance and failure modes before calling it simple.

## Use it when

Technical ambition has become detached from the required result.

## Leave it out when

The small fix would leave a critical requirement unmet.
