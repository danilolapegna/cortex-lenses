# Symbolic Analogy

Use an image to generate a concrete hypothesis about structure or change.

## Steps

1. Choose an image that captures the tension in the problem.
2. Pair it with an unrelated image and inspect roles, boundaries and transformations.
3. Translate one relationship into an operational proposal.
4. Name what the image fails to represent and a test of the proposal.

## Use it when

Literal descriptions keep reproducing the same frame.

## Leave it out when

The image cannot be translated into a mechanism or test.
