# Unifying Mechanism

Synthesize scattered observations into a precise, falsifiable account.

## Steps

1. List supported observations and contradictions in the current explanation.
2. Look for a causal relationship that connects several of them.
3. Write one concise thesis and an unexpected consequence it predicts.
4. Name an observation that would weaken the thesis.

## Use it when

Several reliable signals remain disconnected.

## Leave it out when

The observations are too uncertain to support a synthesis.
