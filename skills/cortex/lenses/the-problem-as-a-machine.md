# The Problem as a Machine

Redraw a confusing failure as inputs, transformations and outputs.

## Steps

1. Describe the observed problem without blame or diagnostic adjectives.
2. Draw inputs, parts, transitions and outputs.
3. Locate the failed transition and the observation that demonstrates it.
4. State what the redraw keeps intact and what inspection it newly enables.
5. Propose the simplest repair and the test that could reject it.

## Use it when

A bug survived fixes aimed at different symptoms.

## Leave it out when

One transition is already proven faulty and its repair is established.
