# Divergent Burst

Push past the first cluster by deliberately varying how an outcome is produced.

## Steps

1. Fix one generative question and its essential constraints.
2. Generate raw moves across different actors, timings, additions, removals and mechanisms.
3. Continue beyond the first repetitive cluster; use up to a hundred moves when proportionate.
4. Return distinct mechanisms with their raw variants intact for later cultivation.

## Use it when

The first few ideas all reproduce one familiar approach.

## Leave it out when

The answer is a calculation or a settled execution step.
