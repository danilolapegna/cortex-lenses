# Change Representation

Change coordinates, variables or relationships while preserving the objective.

## Steps

1. Describe the current representation and the operation it blocks.
2. Choose another scale, state model, graph, symmetry or direction of calculation.
3. Show before, after and every essential dimension kept intact.
4. Name the newly enabled operation and the means needed to perform it.
5. Set a cheapest test and the condition that would make the change fail.

## Use it when

The current representation makes a useful operation hard or impossible.

## Leave it out when

The proposal only renames the problem or weakens its requirements.
