# Challenge Assumptions

Open alternatives by relaxing an assumed necessity.

## Steps

1. List the assumptions behind the baseline.
2. Separate physical limits and binding choices from habits and unknowns.
3. For each negotiable assumption, imagine it false, reversed or optional.
4. Describe a route that becomes possible and the observation needed to test the assumption.

## Use it when

Every proposed solution inherits the same untested requirement.

## Leave it out when

The disputed condition is already a verified hard limit.
