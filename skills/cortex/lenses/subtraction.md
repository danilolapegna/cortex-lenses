# Subtraction

Find a beneficial removal that reduces the cause of the problem.

## Steps

1. Name what the baseline proposes adding.
2. Find one to three removals that could serve the same outcome.
3. Explain which necessary functions must survive each removal.
4. Propose a reversible removal test, including when to restore the part.

## Use it when

Complexity keeps growing while the outcome stays flat.

## Leave it out when

The proposed removal would erase essential capacity.
