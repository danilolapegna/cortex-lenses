# The Ideal with Invariants

Use an ideal outcome to recover functions lost in habitual compromises.

## Steps

1. Describe the ideal experience before negotiating implementation.
2. Extract the functions and benefits that make it ideal.
3. Reintroduce verified constraints one at a time.
4. Design a feasible route that preserves the essential benefits.

## Use it when

The current compromise hides what the solution was meant to deliver.

## Leave it out when

An urgent execution task already has a sufficient design.
