# Make Opposites Cooperate

Look for a mechanism that preserves two apparently competing needs.

## Steps

1. State what satisfying each need would actually mean.
2. Check whether they compete for the same resource at the same time.
3. Try time separation, complementary roles, modularity or different levels.
4. Explain the residual cost and test whether both needs remain satisfied.

## Use it when

The decision is framed as a forced either-or.

## Leave it out when

The trade-off is physical and no separation preserves both needs.
