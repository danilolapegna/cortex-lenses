# Remove the Ritual

Look for work whose continuation matters more than its result.

## Steps

1. Name the result the recurring task is supposed to produce.
2. Identify who uses it and what would happen if it disappeared.
3. Explore solving, removing and redefining the task as separate routes.
4. Propose a reversible pause that would reveal whether the result matters.

## Use it when

A recurring task survives without an identifiable beneficiary.

## Leave it out when

The task meets a verified obligation or protects a necessary function.
