A library people can navigate

Two volunteers, fixed shelves, no budget. Readers need to find a suitable title without adding weekly work or compromising inventory accuracy.

Synthetic rendering example. No independent agent run or reader trial was performed; all proposals and lens notes below illustrate the format.

BaselineAll ideas (8)Lens coverageSelection & stress

The competent, obvious answer

Add a subject map at the entrance and consistent shelf labels. Keep the existing shelf IDs and inventory. Test the map with real reader questions before extending it.

All ideas

01 / questions · Selected

Index by questions, not by shelves

Change Representation

Before

Find an item by knowing its subject category and shelf location.

After

Find a shelf through a reader question tied to its existing shelf ID.

Kept intact
Existing shelf IDs, accurate inventory, two volunteers, no budget and no added weekly work.
New operation it enables
Answer “something for a ten-year-old who loved comics” without knowing the collection.
Cheapest test
Use ten real reader questions and compare time and wrong turns with the current map.
Drop it if
The question index needs weekly upkeep.
How it could work
Mechanism
A stable mapping from reader intent to shelf category removes the need to know the classification.
Decisive dependency
Reader questions must map to persistent subject categories without promising that a particular title is in stock.
Available means
Existing signs, the current shelf map and a short pilot during normal opening hours.
Breaking point
If common questions require title-level availability updates, the index becomes a second catalogue and adds weekly work.
Variants kept intact (2)
  • Put a question-led entry panel beside the existing map.
  • Attach a few stable question labels directly to the relevant shelf markers.
Evidence and limits (1)
  • Illustrative proposal only. No measured retrieval benefit or maintenance saving is claimed.

Start at the first uncertain step

Ladder of Whys

Before

After

Help readers choose their first destination at the entrance.

Kept intact
Existing shelf IDs, accurate inventory, two volunteers, no budget and no added weekly work.
Cheapest test

How it could work
Mechanism

Decisive dependency

Available means

Breaking point
If hesitation starts only when judging books at the shelf, an entrance cue addresses the wrong step.

04 / transfer

Route people like transfers between lines

The Core Verb

Before

Require readers to learn the whole shelf classification.

After

Offer a small sequence of waypoints from the entrance to a stable subject area.

Kept intact
Existing shelf IDs, accurate inventory, two volunteers, no budget and no added weekly work.
Cheapest test
Draw one existing route as three waypoints and compare with the full subject map.
Drop it if
The waypoints duplicate the map without reducing hesitation.
How it could work
Mechanism
A route can be followed locally without memorizing the whole layout.
Decisive dependency
The route must have recognizable, accessible waypoints that remain visible between the entrance and the target shelf.
Available means
Existing signs, the current shelf map and a short pilot during normal opening hours.
Breaking point
If a junction has no visible next waypoint, the route fails exactly where a reader must decide which way to turn.
Analogy and its limit
Origin field: transit navigation. Transfer: staged route decisions linked by stable location IDs. Limit: reading interests overlap, so a route cannot imply one correct destination.
Evidence and limits (1)
  • Illustrative proposal only. No measured retrieval benefit or maintenance saving is claimed.

Opponent Response

Before

After

Place one essential cue on the route readers already take.

Kept intact

Cheapest test

How it could work
Mechanism

Decisive dependency

Existing signs, the current shelf map and a short pilot during normal opening hours.
Breaking point

07 / stability

Test what “no extra weekly work” permits

Explicit Premises

Before

Assume every question index must be maintained alongside inventory.

After

Use only stable shelf-category pointers; never list individual titles.

Kept intact
Existing shelf IDs, accurate inventory, two volunteers, no budget and no added weekly work.
Cheapest test
Inspect recent shelf changes and ask whether ten likely question pointers would have changed.
Drop it if
The pointers depend on changing item-level availability.
How it could work
Mechanism
A category-level index changes only when shelving changes, which may avoid weekly maintenance.
Decisive dependency
The actual frequency of subject moves must be low enough that pointers can be updated within existing sign-maintenance duties.
Available means
Existing signs, the current shelf map and a short pilot during normal opening hours.
Breaking point
If shelf changes force new checks outside existing duties, category-level pointers still violate the no-extra-weekly-work constraint.

08 / borrow-time · Selected

Use one existing duty slot for a reversible pilot

Uncomfortable Routes

Before

Treat all volunteer time as fully allocated forever.

After

Conditionally replace a low-value orientation activity with one pilot, if the volunteers explicitly agree.

Kept intact
Existing shelf IDs, accurate inventory, two volunteers, no budget and no added weekly work.
Cheapest test
Identify a proposed substitution and verify its beneficiary and consequences before scheduling.
Drop it if
Any essential duty would be displaced or the volunteers do not agree.
How it could work
Mechanism
A substitution could fund a test without adding hours, but only if the displaced task is genuinely dispensable.
Decisive dependency
Both volunteers must agree to replace a genuinely dispensable activity, and its beneficiary must retain the service they need.
Available means
Existing signs, the current shelf map and a short pilot during normal opening hours.
Breaking point
If the displaced activity protects an essential service or its beneficiary loses needed help, the pilot cannot use that duty slot.
Evidence and limits (1)
  • Illustrative proposal only. No measured retrieval benefit or maintenance saving is claimed.

After selection / 01

Index by questions, not by shelves

Revisit the original proposal

Checks applied
Fragile Assumption, Causal Mechanism
Strongest objection
The index depends on stable category pointers, and apparent success could come from volunteer hints rather than the index itself.

Fragile Assumption

What the check reveals

Illustrative objection: “something like this comic” may need a specific title that has already been borrowed. Category stability alone does not answer an availability question.

What changes

Limit the pilot to category-level questions. For title-specific requests, point to the existing catalogue or volunteer; keep one shelf ID per entry and make no stock promise.

Causal Mechanism

What the check reveals

Illustrative rival explanation: a volunteer supplying hints could make either aid appear easier to use.

What changes

Alternate the current map and the question index across comparable tasks with a consistent assistance rule. Record first shelf reached, wrong turns and unprompted completion; log any help separately.

Cost and uncertainty
Drafting and observation take volunteer time. Use only an agreed existing orientation slot; preparation time and any later upkeep remain unmeasured.
Revised next test
First inspect the proposed pointers against the current shelf map. If they stay at category level, use the ten reader questions already proposed, alternating aids; record suitability as well as time. This small probe can identify failures, not establish a reliable effect size.
Who would act
Illustrative role: the volunteer responsible for orientation, subject to agreement; nobody has been assigned.
Stop or revise if
Drop the index if it needs title-level upkeep or directs a reader to an unsuitable category. If help or task differences explain the apparent gain, revise the comparison before extending it.

After selection / 08

Use one existing duty slot for a reversible pilot

Revisit the original proposal

Checks applied
Downside and Reversibility
Strongest objection
A free slot on a rota is not proof that the activity being replaced is dispensable.

Downside and Reversibility

What the check reveals

Illustrative counterexample: an apparently quiet orientation slot may be the only time a reader can receive assisted access. Removing it would transfer the cost to that reader.

What changes

Make the conditional slot swap concrete with a one-session probe: identify the current beneficiary and confirm equivalent access with both volunteers before scheduling. Keep the original duty available for immediate restoration.

Cost and uncertainty
No added weekly hours are allowed. The displaced service, consent check and restoration effort must fit existing duties; feasibility is still unknown.
Revised next test
Before scheduling, ask both volunteers what the proposed slot provides, to whom, and how that service would remain available. Proceed with one reversible session only if they agree and no essential duty is lost; otherwise keep the rota unchanged.
Who would act
Illustrative roles: both volunteers decide on the substitution; the orientation volunteer would run it. No real permission has been obtained.
Stop or revise if
Do not schedule if either volunteer disagrees or equivalent access cannot be preserved. During a pilot, restore the original duty immediately if its beneficiary needs it.
